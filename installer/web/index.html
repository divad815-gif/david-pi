YOUR PRIVATE HOME SERVER

Make yourself at home.

Choose a name, a place for your files, and the features your household needs. You can change modules later.

Claim your server

Open this page with the Tailscale account you selected in the terminal, then paste the one-use token shown there. It expires in 15 minutes.

1. Name your home

The server hostname was selected before connecting Tailscale. The display name can be changed independently at any time.

Use a two-letter country code, such as US, GB, or CA. Streaming availability depends on the country.

2. Choose storage and backups

Choose from the prepared local storage found on this server. Setup creates a dedicated folder and preserves everything outside it. Blank drives must be prepared separately.

Advanced: enter an existing folder on a local ext4 filesystem. Setup does not format drives or create the parent folder.

Application content will live in a dedicated david-pi-data folder on your choice.

Advanced: choose an existing folder on a different local ext4 drive.

Backups use a dedicated david-pi-backups folder. You may skip backups and configure them later. Without an independent backup, disk failure can lose your content.

3. Select your modules

Disabled modules keep their content and keys. Phone Backup requires Media.

4. Optional services

Movie Night discovery

Your own TMDB developer account supplies search and country-specific streaming availability. Review provider terms and any applicable costs. Search terms and country go to TMDB; never enter streaming subscription passwords. With no key, your manual watchlist remains available.

Create a TMDB Read Access Token

Provider availability by JustWatch. This product uses the TMDB API but is not endorsed or certified by TMDB.

Recipe discovery

Local recipes and meal planning work without an account. Online discovery sends search terms to TheMealDB and needs your own licensed API key; provider charges may apply.

Review TheMealDB access and terms

Chat notifications

Text and supported images work using a locally generated encryption key. GIF search and native Android push alerts are not available in this release.

Browser push uses your browser vendor’s delivery service. Subscription details are kept on your server. Each browser must also grant permission.

Pi-hole

Optional network-wide DNS blocking requires a separate, deliberate DNS change. Finish this setup, then run sudo david-pi pihole-setup on the server for guided instructions. DNS settings are never changed here.

5. Verify and start

We will check storage, create local keys, and start only your selected features. The next screen shows each step as it finishes. Setup continues if you refresh this page.
