# TMDB attribution asset

`tmdb.svg` is the unchanged approved “Alt short (blue)” TMDB logo, obtained from
[TMDB’s logos and attribution page](https://www.themoviedb.org/about/logos-attribution).
It remains a TMDB brand asset and is used according to its attribution guidance;
it is not represented as an original David-Pi design.

Original asset: https://www.themoviedb.org/assets/v4/logos/v2/blue_short-8e7b30f73a4020692ccca9c88bafe5dcb6f8a62a4c6bc55cd9ba82bb2cd95f6c.svg

The Movie Night credits link back to TMDB, include its required notice, and
identify JustWatch as the streaming-availability source. The logo is served
locally, so displaying credits sends no request to a third party.
