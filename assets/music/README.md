# David-Pi bundled music

These four instrumental tracks are distributed under CC0/public-domain terms and
are included locally so the private David-Pi video maker does not depend on a
third-party service.

- `vaporware.mp3` — “Vaporware,” The Cynic Project.
  Source: https://opengameart.org/content/calm-piano-1-vaporware
- `jrpg-piano.mp3` — “JRPG Piano,” Joth.
  Source: https://opengameart.org/content/jrpg-piano
- `dream.mp3` — “Dream,” jkjkke.
  Source: https://opengameart.org/content/mainmenu-music
- `mystical-piano.mp3` — “Mystical Piano,” Indieteur.
  Source: https://opengameart.org/content/mystical-piano

Each linked source page identifies its track as CC0. Creator names remain visible
in the David-Pi picker even where attribution is not legally required.
