IPHONE · ONE-TIME SETUP

Install once, then pair

One Apple-shared Shortcut. No credentials inside the shared copy.

Apple rejects unsigned Shortcut files downloaded from ordinary websites. This flow uses a Shortcut shared by Apple through iCloud, then binds it to the current David-Pi user with a ten-minute code.

STEP 1

Install Back Up to David-Pi

{% if ios_shortcut_icloud_url %}

Tap the Apple iCloud link on the iPhone, review the actions, then choose Add Shortcut. The shared Shortcut contains no David-Pi token or personal account information.

STEP 2

Pair this iPhone

Keep Tailscale connected. Generate a private code, then open the installed Shortcut. David-Pi determines the owner from the verified Tailscale user who generated the code.

STEP 3

Run the initial backup

Approve All Photos and David-Pi network access when iOS asks. The initial library moves in 200-item batches. For a large first migration, connect power and leave Shortcuts visible. If iOS stops it, run the same Shortcut again; the server checkpoint prevents completed items from being resent.

After the first backup: schedule incremental runs
  1. Open Shortcuts and tap Automation, then +.
  2. Choose Time of Day, then daily or weekly.
  3. Choose Run Immediately.
  4. Add Run Shortcut and select Back Up to David-Pi.
  5. Save it and keep Tailscale enabled.
Private and owner-bound.

Pairing grants this phone upload-only access for its bound user. It cannot browse another person’s manifest, choose an owner, alter collections, share media, or delete anything. Diana must generate her own pairing code while David-Pi recognizes her Tailscale identity.

Household administrator: publish the master Shortcut once
  1. On an iPhone, create a Shortcut named Back Up to David-Pi.
  2. Make its pairing branch accept the six-digit Shortcut Input, POST it as manual_code to {{ public_server_url }}/api/v1/ios-backup/pair, and save the returned device_credential only in the phone’s private Shortcuts folder.
  3. Make its backup branch read that local credential, call /api/v1/ios-backup/status, find the next oldest photos and videos after capture_after, and POST each original to /api/v1/ios-backup/upload-file.
  4. Test pairing and one small upload, remove the test pairing, then use the Shortcut’s share menu and choose Copy iCloud Link.
  5. Put only that public iCloud URL in IOS_SHORTCUT_ICLOUD_URL on David-Pi. Never place a device token in the shared Shortcut or the environment setting.

The exact action-by-action build checklist is in docs/IPHONE_SHORTCUT_SETUP.md in the David-Pi source.
