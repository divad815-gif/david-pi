# Security policy

Do not open a public issue containing credentials, private hostnames, personal
files, database contents, Tailscale device lists, or Pi-hole query history.

Before reporting a problem, run:

```bash
sudo david-pi support-bundle
```

The generated archive is sanitized, but review it before sharing. Security
reports should be sent privately through GitHub's private vulnerability
reporting feature once the repository is published.

David-Pi never requires public port forwarding. Funnel must remain disabled.
